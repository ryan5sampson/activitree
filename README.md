# NOLA

_Know where to go._

Clickable, mobile-first prototype for customer interviews: find fun things to
do nearby in Utah County and know the best time to go. Sample data only, with
no backend and no login.

- **Run locally:** open `index.html` in a browser.
- **Edit content:** change `data.js` (app name, places, prices, busyness by
  hour, groups), then refresh.
- **Publish:** Settings > Pages > Deploy from a branch > `main` / `(root)`.
